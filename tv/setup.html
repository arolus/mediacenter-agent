Название по желанию

Как телевизор будет подписан в приложении.

Ключ TMDb обязательно

TMDb — база фильмов: по ней телевизор узнаёт названия, постеры, описания и актёров. Ключ бесплатный, получить его — минут пять.

Как получить ключ
  1. Зарегистрируйтесь на themoviedb.org/signup и подтвердите почту по ссылке из письма.
  2. Откройте themoviedb.org/settings/api и нажмите «Create» (или «Request an API Key»), тип — Developer, примите условия.
  3. В анкете хватит простых ответов: Application Name — Home media, Application URL — http://localhost, Application Summary — Personal media library. Остальные поля — ваши данные.
  4. После отправки на той же странице появятся API Key и API Read Access Token. Скопируйте любой из них и вставьте ниже.

Ключ OMDb по желанию

Нужен для рейтингов IMDb на карточках. Без него показывается рейтинг TMDb.

Как получить ключ
  1. Откройте omdbapi.com/apikey.aspx, выберите FREE (1000 запросов в день), укажите почту и имя, в «Use» — personal media library.
  2. В письме будет ключ и ссылка активации. Сначала откройте ссылку — без неё ключ не работает.
  3. Вставьте ключ ниже.

Источник поиска по желанию

Чтобы искать и скачивать фильмы прямо с телевизора, подключите источник. Это файл или ссылка — их даёт тот, кто поделился с вами MediaCenter. Без источника телевизор просто показывает то, что уже лежит на нём и на флешке.

Раздача по желанию

Скачанный фильм какое-то время раздаётся другим. Трекеры за это ценят, а у кого рейтинг низкий, тому ограничивают скачивание.

Пока идёт раздача, ваш IP-адрес виден другим участникам. Если вы живёте в стране, где за раздачу преследуют, поставьте «не раздавать».

Детский режим по желанию

В детском режиме на телевизоре нельзя удалять фильмы, искать новые и открывать настройки.

Отчёт — это журнал работы телевизора за последнее время. Ключи и пароли в нём заменены точками. Отправьте его тому, кто помогает вам с MediaCenter.
